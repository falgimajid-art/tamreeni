# تمريني

تطبيق ويب (PWA) لتتبع التمارين الرياضية بتصميم iOS، بيانات المستخدم محفوظة محلياً على الجهاز فقط (localStorage).

## التثبيت على iPhone
1. افتح رابط الصفحة في Safari.
2. زر المشاركة ثم "إضافة إلى الشاشة الرئيسية".

## التشغيل محلياً
```
python -m http.server 8780
```
ثم افتح `http://localhost:8780`.
